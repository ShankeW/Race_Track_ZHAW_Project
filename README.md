# Racetrack

Java-Konsolenprojekt fuer das PM2-Racetrack-Spiel.

## Voraussetzungen

- Java 21

## Anwendung starten

```bash
./gradlew run
```

## Tests ausfuehren

```bash
./gradlew test
```

## Branching Model

Wir verwenden den [GitHub Flow](https://docs.github.com/en/get-started/using-github/github-flow).

1. Neuen Branch erstellen.
2. Gewuenschte Aenderungen umsetzen und committen.
3. Pull Request erstellen.
4. Review einholen.
5. Pull Request mergen.
6. Branch loeschen.
